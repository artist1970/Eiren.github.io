# Public Repository Boundary

This repository is the public-facing home for Eiren.

Public content may describe:

- Eiren's name and public title
- literary personality
- public creative interests
- public-facing skill areas
- guiding principles
- historical creative lineage
- welcoming user experience

Public content should not contain:

- credentials or authentication material
- private continuity archives
- private personal records
- internal security details
- protected routing information
- internal orchestration or federation mechanics
- hidden integration details
- private infrastructure documentation

The public repository should remain understandable without exposing the protected Core.
